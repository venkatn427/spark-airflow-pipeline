5 — Key Architectural Decisions & Why
🔐
Airflow 3 JWT Auth
Airflow 3's LocalExecutor runs tasks as subprocesses that must call back to the Execution API at http://airflow-webserver:8080/execution/ to fetch context and report state.

Both the scheduler (token issuer) and the webserver (token verifier) share a fixed AIRFLOW__API_AUTH__JWT_SECRET. Without this, tasks fail with "Signature verification failed".
🐍
Python Version Parity
PySpark requires identical Python versions on the driver (Airflow container, Python 3.13) and executors (Spark workers). The stock apache/spark:4.0.0 image only has Python 3.10.

A custom spark/Dockerfile installs Python 3.13 via the deadsnakes PPA and sets PYSPARK_PYTHON=python3.13. Airflow sets PYSPARK_DRIVER_PYTHON=python3.
📁
spark-home Volume
Airflow containers need the spark-submit binary to submit jobs. Rather than installing Spark twice, the spark-home named volume is populated by the spark-master container and mounted read-only into all Airflow containers.

Airflow's PATH includes /opt/spark/bin so spark-submit is found without a full path.
🗂️
3-Phase Processing
DAG 02 splits ETL into three sequential Spark tasks (clean → enrich → write) each calling the same script with --phase. This gives:

• Fine-grained task visibility in the Airflow UI
• Ability to retry individual phases without re-running earlier ones
• Intermediate checkpoints in MinIO (staging/clean/, staging/enriched/)
⚡
Dynamic Allocation
All Spark jobs use spark.dynamicAllocation.enabled=true with shuffle tracking. This means:

• Executors scale 0 → 4 based on pending tasks
• Executors are released when idle (no external shuffle service needed)
• The 3 parallel DAG 03 aggregations share the cluster's 4G/4 cores fairly
🪵
Remote Logging to MinIO
Airflow task logs are shipped to s3://pipeline-logs/airflow/ via the apache-airflow-providers-amazon S3 log handler. The connection minio_default uses an AWS-type connection with endpoint_url set to MinIO (path-style access, no TLS).

This makes logs durable across container restarts.
